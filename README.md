# InstaTools

A mobile-friendly, installable demo UI for previewing a social profile and editing sample insights.

## Run locally
Open `index.html` in a browser, or serve this folder with any static web server.

## Deploy to Vercel
Import this folder/repository as a static site. No build command is required; the output/root directory is `.`.

## Included
- InstaTools-branded app directory and Instagram-inspired local profile preview
- Editable demo insights and multiple local profiles
- Local browser storage and PWA manifest/service worker
- Support: clipping0090@gmail.com

## Important limitations
This is an independent demo/simulator. It is not Instagram, does not access Instagram accounts, and does not fetch or verify real Instagram Insights. Values are editable sample data stored in the current browser. No cloud sync, authentication, payment processing, or backend is included.
